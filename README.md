# Turnstone

바둑 + 체스 + 오셀로를 섞은 이상한 보드게임.

## 규칙

9×9 판 위에서 두 사람이 번갈아 돌을 놓는다.

### 돌의 종류

돌을 놓을 때 셋 중 하나를 고른다:

- **탑(Tower)** — 가로·세로로 영향력이 뻗는다 (체스의 룩)
- **궁(Arch)** — 대각선으로 영향력이 뻗는다 (체스의 비숍)
- **마(Leap)** — L자로 영향력이 뻗는다 (체스의 나이트)

### 뒤집기

돌을 놓았을 때, 그 돌의 영향선 위에 있는 상대 돌 너머로 내 돌이 있으면
사이의 상대 돌이 전부 내 색으로 뒤집힌다. (오셀로와 같은 원리지만 영향선이
돌 종류마다 다르다.)

뒤집힌 돌은 종류를 유지한다.

### 영역

빈 칸이 한 색의 돌로만 둘러싸여 있으면 그 색의 영역이다. (바둑 집 계산)

### 승리

판이 꽉 차거나 둘 다 패스하면 끝난다.
점수 = 내 돌 수 + 내 영역 빈 칸 수. 높은 쪽이 이긴다.
